========================================
  OpenAPI Generator Tool
  Standalone Executable Version
========================================

This package contains standalone executables.
No Python installation or source code required!

FILES:
  - openapi-gen-cli.exe - Command-line interface
  - openapi-gen-ui.exe - Web-based user interface
  - START_UI.bat - Quick launcher for UI
  - start_ui.sh - Linux/macOS launcher for UI
  - RUNBOOK_GUIDE.md - Complete Web UI run-book guide
  - RUNBOOK_GUIDE_CLI.md - Complete CLI run-book guide

QUICK START:
  1. Double-click START_UI.bat (Windows) or run ./start_ui.sh (Linux/macOS) to launch the web UI
  2. Or run: openapi-gen-cli.exe --help for CLI usage

The web UI will open in your browser at http://localhost:5000
